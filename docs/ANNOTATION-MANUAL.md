# 标注操作手册 v1.0（内容四分类 + 评论 VAD）

> 适用对象：人工标注员 / 复核员 / LLM 预标注 prompt 设计者。
> 两条铁律：**内容打四分类（含 mixed），评论只打 VAD（不许 mixed）**；两者独立判定，互不参考对方结果。

---

## 0. 两个标注对象，两套口径

| | 对象 | 口径 | 字段 | 是否含 mixed |
|---|---|---|---|---|
| **A** | 视频内容（素材本身） | 四分类 stance + 证据 | `content_label`, `evidence` | ✅ 允许 |
| **B** | 评论区（单条评论） | **VAD 三元组**（valence/arousal/dominance，1–9） | `v`, `a`, `d` | ❌ 禁止 |

> 内容侧**不标强度、不标 VAD**：内容只需回答"素材表达什么立场"（四分类 + 证据）。强度既主观、对 Task B 也无增量信息（观众反应由评论 VAD 直接度量），所以不做。

> 为什么分开：内容情绪（素材想表达什么）与观众反应（评论区实际情绪）是两件事，不能互相推导。内容用离散四分类是因为"混合/反差结构"本身就是内容设计的一部分；评论是海量短文本，离散四分类会把"强度"和"语境"信息压没，用连续 VAD 更可判、更省争议。

---

## 1. 内容四分类（Task A 标注）

### 1.1 定义与判定锚点

| 标签 | 含义 | 典型信号 | 反例（不要选它） |
|---|---|---|---|
| `positive` | 素材整体传达正向情绪（爽感/治愈/燃/萌/期待） | 高光击杀、颜值特写、温情收尾、福利播报 | 只是"画面热闹"≠ positive |
| `negative` | 素材整体传达负向情绪（压抑/失败/恐怖/吐槽/失望） | 翻车、恐怖氛围、失败集锦、明确的吐槽口吻 | 搞笑里的"翻车"通常是 mixed |
| `neutral` | 素材基本无情绪诉求（纯信息/纯演示/纯实录） | 纯攻略讲解、参数罗列、无配乐的录屏 | 有 BGM 和情绪音的不要判 neutral |
| `mixed` | 同一素材内正负情绪**并置或反转**（先惨后爽、先煽情后搞笑、反差打脸） | 社死名场面、反差整活、先抑后扬 | 只是"情绪强烈"≠ mixed |

### 1.2 内容侧不标强度

内容只判四分类 + 写证据。原因：①"素材强度"高度主观（同一条素材两个人给 2 还是 4 都能自圆其说）；②Task B 要的是观众侧强度，直接由评论 VAD 的 arousal 度量，内容侧强度没有增量。

### 1.3 操作步骤（每条素材 1–2 分钟）

1. 打开播放页（`docs/index.html` 或 `clips.csv` 的 `preview_url`），**完整看一遍**（不要只看首帧）。
2. 打开 `clips.csv`，找到该 `clip_id` 行。
3. 在 `human_correction` 列按固定格式填写：
   `content=positive; evidence=12-18s 高光击杀 + 结尾彩蛋; note=可选`
4. `review_status` 改为 `corrected`（存疑改 `flagged`，并把疑问写进 `notes`）。
5. 不确定时**不要猜**：标 `flagged` 并在备注里写"哪一段拿不准"。

### 1.4 证据要求

- 必须能指到**具体时间段**（如 `12-18s`）或**关键帧序号**；
- 同一素材可写多个证据段；
- 禁止只写"整体感觉"。

## 2. 评论 VAD（Task B 标注）

### 2.1 三个维度（1–9 整数）

| 维度 | 1 分 | 3 分 | 5 分 | 7 分 | 9 分 |
|---|---|---|---|---|---|
| **valence 正负** | 极负面（辱骂/弃游/退钱） | 负面（吐槽/失望） | 中性（信息/无感/疑问） | 正面（认可/好笑/期待） | 极正面（狂喜/封神/强烈推荐） |
| **arousal 唤醒** | 极平静（陈述事实） | 较低（平淡回应） | 中等（正常讨论） | 较高（激动/调侃/惊讶） | 极高（大笑/愤怒/震惊刷屏） |
| **dominance 掌控** | 极被动（无力/委屈） | 偏被动（围观/求助） | 中性 | 偏主动（建议/指导） | 极主动（断言/指挥/审判） |

> 只打这三个数，**不要**再给 pos/neg/neu/mixed 分类——分类由 VAD 派生（v 阈值），那是给报表看的，不是给标注员的。

### 2.2 判分规则（按优先级）

1. **反讽/阴阳怪气按真实意图判**：「笑死，这也叫测评？」→ v=2、a=8；「典中典」→ v=2–3、a=6。
2. **梗/黑话按语境判**：先看它回复的对象、视频主题；拿不准时 v=5、a=5，并在 `note` 写该梗。
3. **emoji 计入**：😂🤣 → a+2 左右；😭 → v−2；😡🤬 → v−3、a+2；👍❤️🔥 → v+2；`[色]` → v+1、a+1；`[怒]` → v−3；`[捂脸]` → a+1、v−0.5。
4. **短文本/纯表情**：`哈哈哈` → v=6、a=7；`666` → v=7、a=6；单个表情按 emoji 规则；纯人名/无意义串 → v=5、a=3。
5. **纯信息/求链接/问参数**（"怎么获得""求BGM"）→ v=5、a=4。
6. **情绪与立场分开**：观众骂的是游戏机制（立场负），但语气可能是调侃（情绪 v=5、a=6）——按情绪打分，立场写进 `note`。
7. **一条评论一个三元组**，不因多句拆分。

### 2.3 操作步骤（每批 25 条，约 3–5 分钟）

1. 取评论文件：`data/comments/<clip>_all.json`（已按 `digg` 降序）。
2. 抽样：**Top300 高赞 + 随机 100 长尾**（长尾用于覆盖"梗/反讽"）。
3. 逐条读 → 按 2.2 打分 → 写入 JSON：
   ```json
   {"cid": "...", "text": "...", "v": 6, "a": 7, "d": 5, "note": "梗：神识探查"}
   ```
4. 每批完成后自检 3 条（抽头/中/尾回看是否一致）。
5. 拿不准的标 `flag: true` 并写 `note`，**不猜**。

### 2.4 禁止事项

- ❌ 给评论打 mixed（两条相反情绪就在 v/a 上体现，或记两条注释）
- ❌ 把"视频内容情绪"套到评论上
- ❌ 用词典/模型结果当自己的分（预标注只做参考，人工必须独立判）

## 3. 工作流（工具对应）

```
① 抓评论      scripts/scrape_comments.js <video_url>        → data/comments/*_all.json（按赞降序）
② LLM 预标注  scripts/label_vad.js <all.json> [out] [300]    → *_vad.json（双 rater 平均，1–9）
③ 人工标注    clips.csv（内容四分类）+ 评论 VAD JSON（人工）
④ 复核        review_status；分歧仲裁；网络梗入"未登录词队列"
⑤ 入库        data/clips.csv + data/comments/*_vad.json → 训练数据
```

- 内容播放页：`docs/index.html`（`preview_url` 点开即播，原片在 Release）
- 内容字段：`content_label`（AI 预标）+ `human_correction`（人工真值）+ `review_status`
- 评论字段：`v/a/d`（1–9）+ `note` + `flag`

---

## 4. 质量控制

| 项 | 标准 |
|---|---|
| 双人标注比例 | ≥10% 抽样（每条视频至少 30 条评论、5 条内容） |
| 内容四分类一致性 | Cohen's κ ≥ 0.67（低于则重训口径） |
| 评论 VAD 一致性 | 两 rater 的 Spearman ≥ 0.6（valence/arousal 分别算） |
| 分歧处理 | 差异 v≥3 或 a≥3 的条目 → 第三方仲裁 |
| 网络梗 | 词典未命中但 LLM 给极端 VAD 的 2–4 字片段 → 进 `zh_seed.json` 待补队列 |
| 抽检 | 每批完成后随机回看 3 条 |

## 5. 数据格式

**内容（clips.csv 行）**
```
clip_id, game, format, preview_url, human_correction, review_status, ...
human_correction 格式：content=<positive|negative|neutral|mixed>; evidence=<时间段/帧>; note=<可选>
```

**评论（JSON）**
```json
{"rows": [
  {"cid": "740...", "text": "笑死😂", "v": 6, "a": 8, "d": 5, "note": "", "flag": false}
]}
```

## 6. 常见问题

**Q：一条评论既夸又骂怎么办？**
A：拆成两个判断依据（夸游戏/骂机制），在 v/a 上给主导情绪；`note` 写"夸玩法骂氪金"。评论不打 mixed。

**Q：内容四分类里的 mixed 和评论 VAD 的关系？**
A：无对应关系。内容 mixed 是"素材设计上的正负并置"；评论是逐条的连续情绪。一条 mixed 内容下的评论可能整体偏负。

**Q：为什么评论不用四分类？**
A：四分类会压掉强度与语境；且"mixed"在短评论里无法稳定判定（一条 6 字评论谈不上"混合"）。VAD 保留强度，误差也更小（实测连续 VAD 与 LLM 双 rater 的均值几乎一致）。

**Q：为什么内容不标强度/VAD？**
A：内容侧只回答"素材表达什么立场"（四分类+证据）。强度主观、且 Task B 要的观众侧强度由评论 VAD 的 arousal 直接度量；内容再标一遍强度没有增量，反而增加标注成本与噪声。

**Q：LLM 预标注可以直接用吗？**
A：只作参考。人工必须独立判；预标注与人工不一致的条目正是"网络梗持续学习"的素材来源。
